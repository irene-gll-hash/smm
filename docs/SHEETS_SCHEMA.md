# Поля Google Sheets

## Периоды

`period_id`, `Период`, `Ссылка на папку`, `Решение редактора`, `Комментарий`.

## Разбор материалов

`material_id`, `period_id`, `Название материала`, `Категория`, `Ссылка на папку`, `Что произошло`, `Подтверждённые факты`, `Важная дата или эмбарго`, `Чего не хватает`, `Возможные темы`, `Статус использования`, `Обновлено`.

## План публикаций

`content_id`, `post_id`, `period_id`, `Дата`, `Время`, `Канал`, `Рубрика`, `Тема`, `Краткое описание`, `Зачем это аудитории`, `Материалы`, `Подтверждённые факты`, `Готовый текст`, `Нужен визуал`, `Папка медиа`, `Автор плана`, `Тип`, `Режим подготовки`, `Зафиксировано человеком`, `Версия плана`, `Решение редактора`, `Комментарий редактора`.

Значения списка `Решение редактора`:

- `На согласовании`
- `Одобрено`
- `Нужны изменения`
- `Отклонено`
- `Перенесено`
- `superseded` — предыдущая версия плана

История хранится в этом же листе: пара `post_id` + `Версия плана` уникальна.
Номер версии общий для изменяемого плана периода: первая версия — 1, следующая —
максимальная версия периода + 1. Одинаковое содержание не создаёт новую версию.
При изменении создаётся новый снимок неопубликованных пунктов; предыдущие строки
получают `superseded`. Опубликованные пункты и тексты остаются без изменений.

Значения списка `Режим подготовки`:

- `Написать по материалам`
- `Написать по тезисам`
- `Адаптировать готовый текст`
- `Проверить готовый текст`

Значения списка `Зафиксировано человеком`: `да`, `нет`.

## Тексты

`version_id`, `post_id`, `plan_version`, `draft_version`, `Канал`, `Текст`, `Источники`, `Медиа`, `Статус`, `Комментарий согласующего`, `Автор версии`, `Создано`, `approval_fingerprint`.

Значения списка `Статус`:

- `На согласовании`
- `Одобрено`
- `Переписать`
- `Отклонено`
- `Нужен факт`
- `Заменено новой версией`
- `Запланировано в тестовый канал`
- `Отправлено в тестовый канал`
- `pending_review` — новая редакция текста, ожидающая согласования
- `needs_preparation` — план изменился, требуется подготовить новую версию текста

Существующее значение `На согласовании` продолжает поддерживаться. Новые значения
нужно разрешить в выпадающих списках при использовании строгой проверки данных.

## Справочные листы

- `Каналы`: как минимум столбец `Канал`; остальные настройки площадки могут добавляться отдельными столбцами.
- `Правила`: редакционные и календарные правила.
- `Запреты`: формулировки и типы утверждений, которые нельзя выпускать.
- `Эталоны`: примеры тона. Сервис читает лист и добавляет в него пост только после отдельного подтверждения человека в Telegram. Нужны столбцы `Название / тема`, `Текст поста`, `Канал`, `Рубрика`, `Что нравится / перенять`, `Комментарий`, `Добавлено`, `Добавил`.

В Google Sheets для столбцов с перечисленными значениями нужно включить выпадающие списки. Фильтр создаётся на всю строку заголовков, чтобы период, канал и статус можно было комбинировать.
